# Minecraft HTML / Blockcraft

An unofficial Minecraft-style browser recreation in a single HTML file.

## Run locally

Download `blockcraft-1.21.11-fresh-start.html` and open it in a modern browser with WebGL 2 and IndexedDB support.

The file contains the game source and embedded visual and sound assets. Saves and settings are stored separately in the browser. Multiplayer requires an internet connection.
